# Ruff — шпаргалка проекта

Ruff проверяет стиль Python-кода, частые ошибки и порядок импортов, а также форматирует код. Он запускается через `uv`, поэтому используется версия, закреплённая в `uv.lock`.

Настройки проекта находятся в `pyproject.toml`:

- максимальная длина строки — 100 символов;
- проверяются правила `E` (ошибки стиля), `F` (ошибки Python, включая неиспользуемые импорты) и `I` (порядок импортов);
- файлы `alembic/versions/` исключены: это сгенерированная история миграций, которую не следует массово переформатировать.

Все команды выполняются из корня репозитория.

## Обычный цикл

```text
Изменить Python-код
        ↓
Проверить Ruff
        ↓
Исправить замечания или применить безопасные автоисправления
        ↓
Отформатировать код
        ↓
Повторно проверить перед коммитом
```

## Проверка

Проверить ошибки и порядок импортов:

```bash
uv run ruff check .
```

Проверить, соответствует ли код форматированию, не изменяя файлы:

```bash
uv run ruff format --check .
```

Обе команды должны завершиться с кодом `0` перед коммитом и в CI.

## Автоисправление

Ruff умеет безопасно исправлять часть замечаний, например неиспользуемые импорты и порядок импортов:

```bash
uv run ruff check . --fix
```

Отформатировать Python-файлы:

```bash
uv run ruff format .
```

После автоисправления просмотрите изменения:

```bash
git diff
```

Затем повторите проверки:

```bash
uv run ruff check .
uv run ruff format --check .
```

## Проверка отдельного файла

```bash
uv run ruff check backend/app/main.py
uv run ruff format --check backend/app/main.py
```

## Pre-commit

Установить hook один раз после `uv sync`:

```bash
uv run pre-commit install
```

Запустить все hook вручную:

```bash
uv run pre-commit run --all-files
```

После этого обычный коммит сам запустит Ruff и отменится при ошибке:

```bash
git commit -m "Краткое описание изменения"
```

Исправить замечания и повторить коммит:

```bash
uv run ruff check . --fix
uv run ruff format .
git add .
git commit -m "Краткое описание изменения"
```

## Важные правила

- Не запускайте `--fix` вслепую перед коммитом: сначала просмотрите `git diff`.
- Не исключайте исходный код из Ruff ради скрытия ошибки. Исключения оправданы для сгенерированных файлов, таких как миграции Alembic.
- Ruff не заменяет тесты и не проверяет корректность бизнес-логики. После изменений запускайте также `uv run pytest`.
- Статическую проверку типов (`pyright` или `mypy`) можно добавить позже, когда появится больше FastAPI- и SQLAlchemy-кода.
