# План Renovation Planner

## Стек

- API: Python, FastAPI, SQLAlchemy, Alembic.
- Web: TypeScript, React/Vite.
- БД: PostgreSQL.
- Android: Kotlin, Jetpack Compose.
- iOS: Swift, SwiftUI.
- Инфраструктура: Docker Compose и S3-совместимое хранилище.

## Модель данных

Аккаунт владеет проектами. После MVP он сможет участвовать в чужих проектах по приглашению. Проект содержит адрес, комнаты и покупки. Покупка содержит категорию, суммы, статус, заметку и фотографии.

## Общие правила

- Один Python-бэкенд для Web, Android и iOS.
- API версионируется и документируется через OpenAPI.
- Фотографии хранятся в файловом хранилище, не в БД.
- Деньги передаются в API десятичной строкой, обрабатываются в Python через `Decimal` и хранятся в PostgreSQL как `NUMERIC`; `float` не используется.
