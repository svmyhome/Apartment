# Renovation Planner

Планировщик ремонта для квартир и домов.

## Этапы

1. **Web-MVP** — личный учёт проекта, комнат, покупок и бюджета.
2. **Android** — клиент на общем API.
3. **iOS** — клиент на том же API.

Бизнес-логика, права доступа и данные живут в одном Python-бэкенде. Web, Android и iOS используют его без дублирования расчётов.

## Web-MVP

- Регистрация и вход.
- Проекты: тип объекта, адрес, бюджет и комнаты.
- Покупки: категория, плановая и фактическая сумма, статус и заметка.
- Список, фильтры, итоги и остаток бюджета.

## После MVP

- Фотографии покупок, поиск и экспорт.
- Приглашения, роли и совместная работа.
- Публикация Android- и iOS-клиентов.

## Инфраструктура

В репозитории есть Docker Compose с PostgreSQL (`apartment_db`), FastAPI (`api`)
и Vite-клиентом (`web`). API доступен на `http://localhost:8000`, health-check —
на `http://localhost:8000/api/v1/health`, а web-клиент — на
`http://localhost:5173`.

Для локального запуска нужен Docker Desktop:

```bash
cp .env.example .env
docker compose up --build -d
curl -i http://localhost:8000/api/v1/health
```

Затем откройте `http://localhost:5173`: временная страница должна показать
статус «API доступен».

Остановка окружения без удаления данных PostgreSQL:

```bash
docker compose down
```

Проверки Python-кода и unit-тесты выполняются из корня проекта:

```bash
uv run pytest -m "not integration"
uv run ruff check .
uv run ruff format --check .
```

Web-клиент уже включён в Compose. Автоматическая проверка в GitHub Actions
описана в плане и будет добавлена отдельным следующим шагом.
